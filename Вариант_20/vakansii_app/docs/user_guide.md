# Руководство пользователя

## Главное окно

Слева — таблица вакансий, справа — панели «Напоминания» и «Заметки по этапам».
Сверху — фильтр по статусу и кнопки действий. Напоминания, у которых дата уже
прошла, помечаются «⚠ Просрочено», события в ближайшие 14 дней — «● Скоро».

## Добавить вакансию

1. Нажмите **«+ Вакансия»**.
2. Заполните карточку: компания, позиция (обязательно), вилка, источник,
   ссылка, статус и дата отклика.
3. Если известно ближайшее событие (собеседование, дедлайн тестового),
   заполните блок «Напоминание»: дата + описание. Пустое описание —
   напоминание не создаётся.
4. Нажмите **«Сохранить»**. Вакансия появится в списке, напоминание —
   в панели справа.

## Редактировать и удалить

* Выделите строку и нажмите **«Редактировать»** (или двойной щелчок) —
  откроется карточка с текущими значениями, включая напоминание.
* **«Удалить»** удаляет вакансию вместе с её заметками и напоминаниями
  (с подтверждением).

## Статусы

В карточке выберите статус: «Отклик», «Тестовое», «Собеседование», «Оффер»,
«Отказ». Смена статуса сразу видна в списке и учитывается фильтром
и статистикой. Быстро найти вакансии одного этапа помогает фильтр
«Статус» над таблицей.

## Заметки по этапам

1. Выделите вакансию в списке — в панели «Заметки по этапам» появятся
   её записи.
2. Выберите дату, нажмите **«+ Заметка»**, введите текст (например,
   «HR-скрин пройден, ждём обратной связи»).
3. Заметка с датой добавится в панель; удалить выбранную — кнопка
   **«Удалить»**.

## Напоминания

Панель показывает все события, отсортированные: просроченные → ближайшие →
дальние, с указанием компании и вакансии. Даты собеседований и дедлайнов
задаются в карточке вакансии.

## Статистика

Кнопка **«Статистика»** открывает экран:

* таблица «По статусам (всё время)» — число откликов по каждому статусу
  и доля в процентах;
* таблица «За выбранный период» — те же счётчики для вакансий, у которых
  дата отклика попадает в диапазон; кнопка **«Весь период»** растягивает
  диапазон на все данные.

## Экспорт

Кнопка **«Экспорт»**: выберите формат (CSV для Excel или JSON), что выгружать
(вакансии и/или статистика) и период для статистики. Файл по умолчанию
сохраняется в папку `export/`. CSV записывается в кодировке UTF-8 с BOM
и разделителем «;» — корректно открывается в Excel с русским текстом.

## Сохранность данных

Все изменения сохраняются на диск сразу после каждого действия. При запуске
приложение само проверяет файл данных и, если он повреждён, восстанавливает
данные из последней резервной копии (папка `data/backups`).

## Горячие подсказки

* Двойной щелчок по строке — редактирование.
* Фильтр «Статус» — быстрый отбор вакансий одного этапа.
* Статусная строка внизу подтверждает каждое действие.
