# Вакансии — трекер откликов

Приложение для соискателей: карточки вакансий, этапы отбора, заметки,
напоминания и статистика откликов.

**Реализовано по ТЗ на Python + PyQt6. Графический интерфейс построен
из .ui-файлов Qt Designer и загружается динамически (`PyQt6.uic.loadUi`),
без компиляции в .py.**

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Требуется Python 3.10+ и установленный PyQt6. Приложение кроссплатформенное
(Windows, macOS, Linux); для сборки интерфейса ничего компилировать не нужно.

## Структура проекта

```
vakansii_app/
├── main.py                  # точка входа; UI-слой, динамическая загрузка .ui
├── requirements.txt         # зависимости (PyQt6)
├── ui/
│   ├── main_window.ui       # главное окно: список, напоминания, заметки
│   ├── job_dialog.ui        # карточка вакансии (форма + напоминание)
│   ├── stats_window.ui      # экран статистики
│   └── export_window.ui     # окно экспорта
├── app/
│   ├── logic.py             # ApplicationLogic — бизнес-логика
│   └── data_access.py       # DataAccessLayer — JSON-хранилище
├── data/
│   ├── jobs.json            # файл данных (создаётся/восстанавливается сам)
│   └── backups/             # последние 5 резервных копий
├── docs/
│   ├── data_format.md       # описание структуры файла данных
│   ├── user_guide.md        # руководство пользователя
│   └── architecture.md      # техописание взаимодействия модулей
├── tests/
│   └── test_logic.py        # тесты логики и хранилища (без GUI)
└── export/                  # сюда по умолчанию попадают выгрузки
```

## Демо-данные

`data/jobs.json` изначально заполнен примерами из рабочего документа
откликов (Каскад Тех, Северный код, Атлас Софт, Ладога Дев). Позиция
и вилка для «Ладога Дев» добавлены как демо-заглушка — в исходном документе
указан только факт отказа от 28.10. Данные можно смело удалять и вести свои.
